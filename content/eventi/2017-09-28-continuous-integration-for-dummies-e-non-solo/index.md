Per quando ne hai bisogno? "ieri". Quante volte avete sentito questa frase? Se lavorate nell'IT penso parecchie. Rilasciare software in maniera rapida senza sacrificare la qualità però non è semplice: la continuous integration (CI) è un insieme di pratiche che puntano ad automatizzare i processi di sviluppo, riducendo i rischi ed aumentando la fiducia del team nel rilasciare un software di qualità

Alcuni degli argomenti trattati

• principi della continuous integration

• creazione di uno script di build

• scegliere un server di CI: build or buy?

• test automatici

• migrazione dei dati

• automatizzare i deploy
